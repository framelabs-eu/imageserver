# WSGI Proxy Server

This is a minimal example on how to use the library with [WSGI](https://wsgi.readthedocs.io) to proxy images from other servers to ArtFrame devices.
The example backend is pexels.com.

# Usage
1. Get a Pexels API key [here](https://help.pexels.com/hc/en-us/articles/900004904026-How-do-I-get-an-API-key)
2. Run ```PEXELS_API_KEY=YOUR_KEY python3 proxy_server.py```
